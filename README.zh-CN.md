# 四片 · X 图片切分

[English](README.md)

一款 Chrome 扩展，将横图切成四张竖图，按顺序预览后加入 X 帖子，无需手动保存切图文件。

## 功能

- 支持拖入、选择、粘贴图片，或读取剪贴板中的图片。
- 支持 JPG、PNG、WebP 输入，可输出 JPG 或 PNG。
- 从左到右编号；图片宽度不能被四整除时，保留全部像素。
- 预览四张切图后，将其加入 X 发帖窗口的空附件区。

## 安装

1. 在 Chrome 打开 `chrome://extensions`，开启**开发者模式**。
2. 点击**加载已解压的扩展程序**，选择项目内的 `extension` 文件夹。
3. 刷新 X 页面，即可看到**四片**按钮。

Chrome 可能提示允许读取剪贴板。扩展仅在点击**读取剪贴板并切图**时读取剪贴板。

## 使用

1. 打开 X 发帖窗口，展开**四片**面板。
2. 拖入或选择图片，也可以在面板内粘贴图片。若从网页复制，请在图片上右键选择**复制图片**，回到面板后点击**读取剪贴板并切图**。
3. 检查预览，点击**加入当前帖子 · 4 张**。
4. 在 X 中确认附件顺序后自行发布。

当前帖子的附件区需要为空。剪贴板图片通常没有原始文件名，切图会使用带时间戳的名称。

## 开发

安装 [Bun](https://bun.com/) 后，在项目目录运行：

```sh
bun build.ts
bun test tests/clipboard.test.ts
```

构建会更新 `extension/` 和项目根目录中的可加载文件。构建后，在 `chrome://extensions` 重新加载扩展并刷新 X。
